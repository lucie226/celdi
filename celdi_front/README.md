# Celdi - Frontend (Angular)

Interface de gestion de prospects, connectée à l'API Spring Boot.

## Lancer le projet
1. Démarrer d'abord le backend (http://localhost:8080).
2. Dans ce dossier : npm install
3. Puis : ng serve
4. Ouvrir http://localhost:4200
